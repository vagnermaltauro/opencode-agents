---

**Pro Tips:**
1. Be specific in your prompts for better results
2. Combine agents for complex workflows
3. Use @agent help to understand agent capabilities
4. Adjust agent permissions in their .md files if needed
5. Set frequently-used agents to `mode: primary` for Tab access

**Remember:** All agents are invoked with `@agent-name` in OpenCode!
